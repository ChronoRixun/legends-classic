The unnamed-placement regression is covered by synthetic Python reverse-load tests and
`tests/unit/export_lcsave_unnamed_vector.py`. Its invented zone contains an unnamed,
unoccupied numbered placement and a separate legacy streamed state eligible for promotion.
The exported vector matches the C++ reverse reader for native bytes and capture metadata.

Candidate 0.2.0g also completed the second HAARP exterior tank reveal from a converted
slot 6 copy loaded through the normal Load menu. This was a **staged** check: party entry
near the trigger and the door-objective prerequisite were staged. Real movement crossed
the trigger; the reveal itself, motion path and completion were not invoked manually.
The scene locked controls, moved and removed the cinematic tank, then unlocked controls.
All four heroes remained alive at the end, and real movement moved the controlled hero
afterward. Earlier staging attempts placed heroes below terrain; those attempts do not
establish navigation or collision correctness. The final successful run used a corrected
entry position. This check proves the reveal sequence, not natural navigation to it.

The follow-up changes no C++ runtime code, generated content, content version or save
layout. The candidate DLL is unchanged. This does not close the separate retained-state
live coverage gap for the earlier NYC zones.
